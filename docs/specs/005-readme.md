# 005 README

## Goal

Write a README that explains what this repo is and how to run it.

## Context

The repo has no README. This is a small Python WebSocket server that is part of a larger home irrigation system.

## Scope

Write `README.md` with these sections in order:
1. Title and one-sentence summary (with CI badge)
2. Why I built it
3. How it fits (link related repos)
4. Stack
5. Running it locally
6. Configuration (table of environment variables)
7. Tests
8. How I work on it

## Out of scope

- Screenshots (no UI).
- Architecture or Components sections (this is not the main repo of the project).

## Acceptance criteria

- `README.md` exists with all required sections.
- CI badge at the top links to the correct workflow.
- Writing follows the style rules (first person, no dashes as punctuation, no semicolons, no colons in prose, no filler words, no emoji).

## Test plan

- Read the README and confirm it meets the writing rules and section requirements.
